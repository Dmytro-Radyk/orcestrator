# Codex через наявну підписку

Підписка ChatGPT із включеним Codex є окремим допустимим джерелом доступу; вона не позначається безкоштовною. Вхід через API-ключ і credit-based тарифи залишаються забороненими. Старе безумовне блокування всіх Codex-маршрутів замінено умовним режимом `subscription_quota_guarded`.

## Умови ввімкнення

1. Штатний metadata API підтверджує ChatGPT-вхід, тариф із включеним доступом і поточну квоту.
2. Metadata підтверджує відсутність додаткових кредитів: `hasCredits: false`, `unlimited: false` і нульовий баланс. Сам нульовий баланс не доводить включений доступ; усі умови перевіряються разом.
3. Користувач перевірив у Codex Settings → Usage & Billing, що Automatic reload вимкнений, і підтвердив це оператору. CLI не повертає цей параметр. Після такого підтвердження в приватному `.env.local` можна задати:

```dotenv
ORCHESTRATOR_CODEX_AUTO_RELOAD_DISABLED=1
```

Цей параметр є підтвердженням стану акаунта, а не командою зміни білінгу. Він не вмикається автоматично за фактом підписки або порожнього балансу. Для скасування підтвердження приберіть параметр і перезапустіть сервер. Не вмикайте Automatic reload або платні кредити під час контрольованого запуску.

## Контроль виконання

Спільна черга registry пропускає по одному Codex-виклику, включно з AI-директором і виконавцями. Після очікування в черзі доступ перевіряється знову. Під час виклику перевірки Codex metadata повторюються приблизно раз на п'ять секунд плюс тривалість metadata-запиту; timeout такого запиту — вісім секунд.

Виклик не починається або отримує abort, якщо будь-яке відоме вікно використання досягло 90%, доступна додаткова кредитна оплата, змінився тариф/вхід або перевірка перестала підтверджувати умови. Резерв у 10% зменшує ризик перетину ліміту під час однієї задачі. Купівля кредитів, поповнення й використання платних reset не виконуються. Коли Codex заблокований квотою, можна повторити AI-підбір серед доступних безкоштовних маршрутів; активна задача не переноситься на іншу модель мовчки.

Для inference примусово задаються `forced_login_method="chatgpt"`, `model_provider="openai"` та ігнорування користувацької конфігурації. Дочірній процес не отримує API-ключів, endpoint overrides або `NODE_OPTIONS` із середовища. Штатне сховище входу не копіюється. Метадані акаунта й платіжні суми не потрапляють у публічну документацію.

## Межа гарантії

Це контроль квоти на стороні оркестратора, **не атомарна заборона кредитних списань на сервері OpenAI**. Встановлений CLI не має підтвердженого перемикача «лише включена квота». Між перевірками використання може змінитися, зокрема через інший клієнт. Програма не повинна називати цей режим `included_only` або обіцяти гарантовану нульову додаткову вартість. Умови вимкненого поповнення й відсутності платних кредитів мають залишатися чинними.
