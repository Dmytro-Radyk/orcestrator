# Перевірка інтеграцій та UI — 2026-11-16

Перевірено поточний локальний прототип на Windows з Node.js 24.13. Результати описують конкретний контрольний сценарій, а не гарантію якості всіх моделей або незмінності квот провайдерів.

## Бібліотека агентів і майстер

- Живий каталог повернув 39 маршрутів: 8 Codex, 13 безкоштовних OpenCode та 18 Antigravity. Після групування рівнів роздумів бібліотека містить 28 карток моделей. Кількість залежить від встановлених CLI, доступу та моменту сканування.
- У браузері перевірено одну картку Claude Opus замість окремих карток на кожен рівень. У діалозі додавання доступні Low, Medium та High; вибір Medium не змінює інші профілі. Скасування діалогу не змінює команду.
- Перевірки контракту покривають збереження точного модельного маршруту, передачу Codex reasoning effort та відхилення недоступного рівня до виклику моделі.
- Виправлено оновлення каталогу перед AI-підбором команди: тривале продумування ідеї більше не залишає цей крок зі старим списком кандидатів. Після зміни перевірено синтаксис; окремого повторного проходу цього кроку в браузері не виконували.

## Сонячна система

У браузері перевірено вибір планети, наближення до деталізованої Землі, обертання камери навколо вибраної планети та повернення до Сонця. Після скидання список цілей показує Сонце. Видимі хмари, материки, відблиски й нічні вогні.

Виправлено обмеження розміру текстури перед GPU upload, зокрема для нічної карти Землі: зображення зменшується до можливостей GPU. Прибрано чотири виклики GLSL `smoothstep` зі зворотним порядком меж, поведінка яких не визначена специфікацією. Тести камери перевіряють стеження за рухомою ціллю, безпечну відстань, скидання й reduced motion; тести текстур перевіряють обчислення допустимих розмірів.

Декодування всіх 21 локальних зображень успішне; разом приблизно 12,86 MB, найбільша сторона — 4096 px. Перевірено атрибуцію джерел, додано повний MIT notice для ресурсів Three.js. Числовий FPS benchmark і перевірка вузького viewport до цього проходу не входили.

## Реальний запуск через UI

Через інтерфейс створено контрольний проєкт функції фільтрації унікальних скінченних чисел: ідея → концепція → план із двох задач → команда → точний підбір маршрутів → запуск. План зберігся після перезапуску сервера та оновлення сторінки.

Початковим керівником був `antigravity:gemini-4-hydrogen-high`. Він вибрав безкоштовний `opencode:opencode/big-pickle` для реалізації та включений у підписку `antigravity:gemini-3.8-flash-low` для незалежного читання й перевірки.

1. У промпті контрольної задачі було закладено одноразову відмову `QA_RECOVERY_PROBE` до появи діагностики відновлення. Це умова тестового проєкту, а не поведінка звичайних задач.
2. Перше відновлення перепризначило задачу на `opencode:opencode/hy4-flash-free`; цей маршрут повернув реальну помилку доступності провайдера.
3. Друге відновлення виключило обидва попередні маршрути та вибрало `opencode:opencode/iceman-free`. Реалізація завершилася успішно.
4. Gemini Flash Low виконав незалежну перевірку. Дев'ять згенерованих тестів пройшли під час реалізації та повторно у перевірці з доступом лише для читання.

Запуск зберіг той самий ідентифікатор, завершився зі статусом `completed`, двома раундами відновлення та шістьма викликами. Пауза під час першого відновлення утримала нового виконавця: після готовності призначення лічильник лишався на двох викликах до натискання «Продовжити».

У цьому проході керівника відновлення автоматично вибрала політика: обидва раунди виконав Big Pickle. Виявлену втрату явно вибраного початкового керівника виправлено після проходу: тепер збережена AI-пропозиція передає його у конфігурацію відновлення. Це покрито HTTP-тестом перенесення налаштування та перевіркою заборони підміни недоступного керівника; повний сценарій із моделями після цього виправлення повторно не запускався.

Прийняті два файли додатково перевірено незалежно від відповідей моделей. Їх скопійовано в окремий каталог, звірено SHA-256 до та після перевірки й виконано в механічному sandbox без нового модельного виклику. Разом пройшли 12 тестів: дев'ять згенерованих та три незалежні, включно зі 100 детермінованими наборами змішаних значень. Перевірено незмінність вводу, порядок перших значень, `0`/`-0`, відкидання нескінченностей, `NaN` і нечислових значень та TypeError для не-масивів.

## Публікація

Фінальний `npm test`: 133 тести пройшли, помилок і пропущених тестів немає. Синтаксис перевірено для 58 JavaScript-модулів; `git diff --check` пройшов. Локальні дані проєктів, контрольні workspace, сирі журнали, стан авторизації та `.env.local` зберігаються поза Git. До публічного звіту включено лише опис сценарію й результати.
