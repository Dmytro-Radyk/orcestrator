# Каталог моделей і політика доступу

## Реалізовано

Розділ «Підключення» отримує метадані через локальний сервер: встановлені native CLI, стан входу, тариф, точні model IDs, квоти, джерело й час перевірки. Наявність executable або входу сама по собі не підтверджує підписку чи безкоштовність моделі.

| Конектор | Поточна підтримка |
| --- | --- |
| Codex | Пошук CLI; штатні `account/read`, `model/list` із пагінацією, `account/rateLimits/read`; нормалізація підписки й квот |
| Claude Code | Пошук CLI та `auth status`; каталог моделей і умови оплати ще не підтверджуються |
| OpenCode | V2 model.list, перевірка порожнього auth list, anonymous runtime з нульовими тарифами; виконання текстових задач без інструментів |
| Ollama | Пошук CLI; локальний режим ще не дозволений поточною політикою |

Сканування не запускає inference: JSONL-транспорт має закритий перелік metadata-методів і відхиляє запити інструментів від дочірнього процесу. Каталог зберігається у приватному `.orchestrator/ui/state.json`. Email, ключі, токени, баланс кредитів, платіжні дані й шляхи executable не потрапляють до каталогу або відповіді UI. Це перевірка підтримуваних інтеграцій у PATH і відомих каталогах, а не суцільне читання диска чи сховищ паролів.

## Без додаткових списань

Єдина політика дозволяє лише підтверджений free tier або включений доступ наявної підписки. Потрібні актуальна перевірка, доступна квота, підтримуваний runtime і підтверджена межа `included_only`. Metered API, промокредити платного API, невідомі тарифи й платне продовження виключені. Дані перевірки чинні до п’яти хвилин; перед кожним фактичним викликом виконується новий скан.

Обмеження застосовані до планувальника UI, запусків UI, `npm start` та `node src/cli.js run`. Каталог у JSON проєкту, вибір у браузері чи збережений кеш не можуть дозволити виклик. Executable визначається сервером. Демо працює без моделі й без сканування. Низькорівневі адаптери залишаються окремими бібліотечними компонентами; їхня наявність не означає дозвіл маршруту у продукті.

**Codex через підписку:** за підтвердженого ChatGPT-входу, квоти та відсутності додаткових кредитів доступний режим `subscription_quota_guarded`. Потрібне також підтвердження користувача про вимкнений Automatic reload; CLI не повертає цей параметр. Контроль перевіряє квоту до й під час роботи, серіалізує Codex-виклики та зупиняє їх при вичерпанні п’ятигодинної чи тижневої квоти або досягненні 90% в іншому вікні. [Увімкнення, захист API-входу та межі](CODEX-SUBSCRIPTION.md). Історичні запуски й файли доступні незалежно від стану підписки.

OpenCode вже має окремий anonymous-конектор із перевіркою нульових тарифів. Автоматичний планувальник використовує допустимий маршрут; новий `/api/routing` дає AI-пропозицію точних моделей для задач із серверною перевіркою. Це ще не виміряний рейтинг найсильніших моделей. [Контракт керівника, інтеграція UI та межі](AI-DIRECTOR.md).

## API та модулі

- `GET /api/connections` — актуальні рішення політики для кешованих метаданих.
- `POST /api/connections/scan` — нова metadata-перевірка без модельної задачі.
- Обидва запити потребують локального same-origin доступу та `X-Execution-Token`; POST — JSON.
- `scripts/model-registry.js` — discovery, нормалізація, збереження, повторна авторизація викликів.
- `src/model-policy.js` — рішення політики та відбір допустимого кандидата на керівника.
- `src/metadata-rpc.js` — обмежений stdio JSONL-транспорт.
- `apps/web/src/connections.js` — каталог у космічному UI.

Перевірено читання типу тарифу, доступних моделей і квот через Codex metadata API. Дані конкретного акаунта не включені в публічний репозиторій. Скан каталогу не виконує inference; окремі живі перевірки концепції та AI-пропозиції маршрутів виконані через free-модель із нульовою вартістю.

62 автоматичні тести охоплюють ядро й UI API, політику тарифів, прострочені дані, квоти, захист серверного каталогу від підроблених клієнтських даних, приватність нормалізації, metadata handshake/пагінацію, завершення процесу, anonymous-конектор та перевірку AI-рішень.
